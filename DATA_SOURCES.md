# Data sources and licences

All map data is bundled in `app/src/main/assets/map/` and is generated by `tools/build_data.py`. No game text, graphics or data was taken from megyejatek.hu.

| Data | Source | Licence | Used for |
|---|---|---|---|
| County and Budapest boundaries | [OpenStreetMap](https://www.openstreetmap.org/copyright), `boundary=administrative`, `admin_level=6` | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) | `counties.geojson`, `outline.geojson`, neighbours, label points |
| Settlement boundaries (centroids) | OpenStreetMap, `admin_level=8` | ODbL 1.0 | city coordinates in `cities.json` |
| Settlement names, counties, population | KSH – Magyarország helységnévtára ([ksh.hu](https://www.ksh.hu)) | Free to reuse with the source credited (check KSH's current terms of use) | `cities.json` (which places pass the 10,000 cut, population) |
| Rivers and lakes | [Natural Earth](https://www.naturalearthdata.com/) 10m `rivers_lake_centerlines`, `rivers_europe`, `lakes`, `lakes_europe` | Public domain | `water.geojson` |
| County names, ISO 3166-2 codes, seats | Public administrative facts, typed into `AREAS` in the script | n/a | `counties.json` |

**What this means for the repo:** the app's code is MIT. The generated files in `assets/map/` contain OpenStreetMap data, so they are a derivative database under the ODbL: they stay under ODbL, and the app shows "© OpenStreetMap közreműködők" on the Források page and in the map corner.

Natural Earth was not used for the county polygons because its admin-1 layer lists the 23 cities with county rights as separate units with old spellings, so it would need re-merging.

## Current state: interim data

Until the full pipeline has been run, `assets/map/` holds **interim data built only from Natural Earth** (public domain): the 20 areas with their seats, rivers and lakes, but only about 20 cities (`meta.json` has `"interim": true`). It was produced by the same `build` step, with `--simplify 40%` because Natural Earth is already coarse. Running `fetch` + `build` below replaces it with the OSM/KSH data.

## Regenerating the data

Needs Python 3.10+ and Node.js (for `npx mapshaper`). Run from the repo root.

```bash
python3 -m venv tools/.venv && source tools/.venv/bin/activate
pip install -r tools/requirements.txt

# 1. Download the settlement table from KSH (Helységnévtár → letöltés, .xlsx) once.
# 2. Fetch the raw sources (OSM via Overpass, Natural Earth via GitHub) into tools/cache/:
python tools/build_data.py fetch --ksh ~/Downloads/<helysegnevtar>.xlsx

# 3. Build the app assets:
python tools/build_data.py build
```

`build` prints the number of cities above 10,000 inhabitants (the count depends on the KSH edition) and the size of each output file. It refuses to write anything if a check fails:

- exactly 20 areas (19 counties + Budapest)
- neighbours are symmetric and every area has at least one
- Pest's seat is Budapest, and Budapest is not one of Pest's cities
- every county seat is in the city list
- every city lies inside its KSH county

Neighbours are computed from shared borders longer than 1 km. If a pair ever needs fixing by hand, add it to `tools/neighbour_overrides.json` (`"add"` / `"remove"` lists of `["HU-XX", "HU-YY"]` pairs).
